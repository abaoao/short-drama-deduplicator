# short-drama-deduplicator

这是一个面向短剧/短视频素材预处理的本地工具，目标不是绕过平台审核，而是帮助你做“内容差异化”和“多版本生成”。

它适用于：

- 同一短剧素材做多个版本
- 在上传前进行素材变体检查
- 提升镜头差异、字幕差异、节奏差异、色彩差异
- 提高素材可剪辑性和原创度感

## 免责声明

该工具仅用于：

- 本地素材变体生成
- 剪辑前的多版本输出
- 原创度增强和素材多样化处理

它不保证一定能通过平台审核，也不构成平台规避方案。

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

请确保已安装 FFmpeg：

```bash
ffmpeg -version
```

## 直接使用

### 自动模式（默认）

```bash
python main.py --input ./input --output ./output --mode auto --count 4 --title "你的标题"
```

### 颜色增强版

```bash
python main.py --input ./input --output ./output --mode color --count 2
```

### 字幕版

```bash
python main.py --input ./input --output ./output --mode subtitle --count 2 --title "短剧标题"
```

### 快节奏版

```bash
python main.py --input ./input --output ./output --mode speed --count 2 --speed 0.9
```

### 重构镜头版

```bash
python main.py --input ./input --output ./output --mode reframe --count 2
```

### 音乐混合版

```bash
python main.py --input ./input --output ./output --mode music --count 1 --music ./music/ambient.mp3
```

```text
output/

├── source_subtitle.mp4
├── source_speed.mp4
├── source_reframe.mp4
├── report.json
└── ...
```

`report.json` 会记录每个生成版本对应的原始素材和输出文件。
